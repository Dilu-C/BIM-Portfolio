# Communication Language Rule

## Guidelines
- **Artifacts & Plans:** Whenever creating or updating user-facing artifacts (e.g., implementation_plan.md, walkthrough.md, 	ask.md), the content MUST be written in the Sinhala language.
- **Script:** Always use standard Sinhala characters (සිංහල අකුරු) for these documents, not Singlish (English transliteration).
- **Exceptions:** Code snippets, file paths, and technical terms/commands (like generate, utton, etc.) should remain in English to avoid confusion.
